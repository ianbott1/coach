Round 109's measurement scripts (not part of run-all). From the repo root, after a build:
- r109-probe.js [league] [n]: a starter swapped for a backup 12-30 points worse, the chance and the best plan.
- r109-grok.js [file prefix]: Grokbot's round-13 teams, the card's chance and reason line before and after each swap.
- r109-modal.js [league]: how often a club's usual plan is the card's pick over every live opponent.
- r109-vs.js / r109-vs2.js file [teams] [games]: played against shown (vs2: the change from engine 22, common dice).
- r109-level.js file [teams] [games]: your path's scoring and wins following the card, engine 23 against 22.
- r109-spread.js, r109-bsp.js, r109-spq.js, r109-tonight.js: the spreads and the starter's worth behind the constants.
